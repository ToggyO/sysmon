Detailed Description

Iterator for traversing system process information entries.

Provides sequential access to a collection of process information objects. Each iterator instance typically represents a snapshot of the current system state at the moment of iterator creation, unless the concrete implementation specifies otherwise.

The typical usage pattern:

auto it = provider.create_iterator();
while (it->has_next()) {
std::unique_ptr<IProcessInfo> info_ptr = it->next();
// process info...
}
