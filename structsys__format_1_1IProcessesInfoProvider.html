virtual std::unique_ptr<IProcessInfoIterator> sys_format::IProcessesInfoProvider::create_iterator ( ) const
pure virtual

Creates a new iterator for traversing system process information.

This method constructs and returns a new iterator that provides sequential access to the collection of currently available system processes. Each call produces a separate iterator instance whose lifetime is owned by the caller.

A std::unique_ptr managing a newly created instance of IProcessInfoIterator.
